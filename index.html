Словарик

Короткие определения всех слов из глав. Удобно повторить перед уроком.

Алгоритм
Точная последовательность действий, которая приводит к цели.
Язык программирования
Язык для общения с компьютером. Каждая команда в нём понимается только одним способом.
Программа
Алгоритм, записанный на языке программирования.
Функция
Алгоритм с именем. Есть готовые (print(), input()), а свои создают командой def.
Аргумент
То, что передаём функции в скобках: print(5) — здесь 5 аргумент.
Параметр
Имя в скобках после def: def hello(name). При вызове в него попадает аргумент.
return
Команда, которая возвращает результат функции и сразу её завершает. Без return функция возвращает None.
Локальная переменная
Переменная, созданная внутри функции. Существует только пока функция работает.
Переменная
Имя, за которым хранится значение. Значение можно менять.
Присваивание
Команда имя = значение: запомнить значение под этим именем.
Тип данных
Вид значения: целое число int, дробное float, текст str.
Строка (str)
Текст в кавычках: 'Привет', '42'.
Ввод и вывод
Ввод — данные от пользователя (input()), вывод — данные на экран (print()).
Интерпретатор
Программа, которая читает твой код и выполняет его строчку за строчкой.
Индекс
Номер символа в строке. Считается с нуля: s[0] — первый символ.
Срез
Часть строки s[a:b]: с номера a до b, сам b не входит.
Метод
Функция, которая пишется через точку после значения: s.find('x'), s.lower().
Комментарий
Пояснение после #, которое Python пропускает.
Логический тип (bool)
Тип с двумя значениями: True (истина) и False (ложь).
Условие
Выражение, которое бывает верным или неверным: age >= 12.
Условный оператор
Команда if / elif / else, которая выбирает, какие команды выполнить.
Отступ
4 пробела в начале строки. Показывает, что команда находится внутри if, while или for.
Цикл
Команда, которая повторяет действия: while — пока условие верно, for — для каждого элемента.
Шаг цикла (итерация)
Одно выполнение тела цикла.
Счётчик
Переменная, которая считает шаги цикла: count += 1.
Бесконечный цикл
Цикл, условие которого никогда не становится ложным. Программа «зависает».
Последовательность
Элементы, которые стоят по порядку: строка, range().
Вложенность
Конструкция внутри другой конструкции: if в цикле, цикл в if. Каждый уровень — ещё 4 пробела отступа.
break
Команда, которая сразу прерывает ближайший цикл.
Отладчик
Инструмент, который выполняет программу по шагам и показывает значения переменных. Помогает искать ошибки.
Стандартная библиотека
Набор готовых инструментов, который устанавливается вместе с Python: встроенные функции и модули.
Модуль
Файл .py с функциями. Бывают стандартные (random, time) и свои.
import
Команда подключения модуля: import random или from random import randint.
Ошибка (исключение)
Сообщение Python о том, что он не смог выполнить строку. Последняя строка сообщения говорит, что именно не так.

Ничего не нашлось. Попробуй другое слово.
