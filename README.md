# Пособие по Python

Основы программирования на Python для начинающих: от первой строчки кода до циклов.

**Открыть пособие:** https://twzuka.github.io/python-posobie/

## Главы

1. Первые программы: `print()` и вычисления
2. Переменные и ввод данных
3. Строки
4. Короткий и понятный код
5. Условия: `if` и `else`
6. Сложные условия: вложенный `if` и `elif`
7. Цикл `while`
8. Цикл `for`
9. Собираем всё вместе: вложенные конструкции

В каждой главе есть объяснение с примерами, пошаговый разбор программ, частые ошибки и вопросы для самопроверки.
